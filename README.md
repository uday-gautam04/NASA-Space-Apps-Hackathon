# NASA Space Apps Hackathon

## Project Overview
This project was developed as part of the NASA Space Apps Hackathon. It analyzes NASA-related datasets and generates insights through data visualization and machine learning techniques.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Structure
DATASET/
Nasa.ipynb
main.py
requirements.txt

## Features
- Data preprocessing
- Exploratory Data Analysis
- Correlation heatmap generation
- Dataset visualization
- Predictive analysis

## How to Run
pip install -r requirements.txt
python main.py
